03 · PLANEJAMENTO DE AULA

Planejamento semanal para o Ensino Médio Técnico.

Essa ferramenta foi pensada para o contexto do Ensino Médio Técnico, seguindo os escopos e sequências dos cursos técnicos e organizando o trabalho em uma lógica semanal, como a plataforma da Educação Profissional.

A ideia foi agilizar o planejamento de aula. Em vez de começar do zero a cada semana, o recurso ajuda a montar uma base organizada para o professor adaptar à turma e ao contexto real da aula.

Como funciona

O projeto usa um modelo do Word para o planejamento de aula e uma mala direta com dados de uma planilha. A ideia é gerar uma estrutura pronta de forma mais rápida e menos repetitiva.

Para isso, você precisa de uma planilha de grade horária com campos como Dia (Seg, Ter, Qua, Qui, Sex), Horário, Turma e Disciplina, além dos arquivos de escopo-sequência para cada ano e um arquivo de configuração em JSON.

O resultado do processamento é uma planilha com várias colunas contendo os dados das aulas da semana, pronta para ser usada como base para gerar o planejamento.

Sobre a mala direta no Word

Para criar esse tipo de documento, o processo usa a funcionalidade de mala direta do Word com uma planilha Excel como fonte de dados. Isso permite que cada linha da planilha vire um bloco de conteúdo do documento, como uma aula ou uma sequência de planejamento.
