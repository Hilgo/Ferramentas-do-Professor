Antes de começar: o que são extensões e scripts?

Uma extensão de navegador é um pequeno complemento instalado no Chrome ou Edge para acrescentar uma função nova ao navegador — como se fosse instalar um aplicativo pequeno dentro dele.

O Tampermonkey é uma extensão gratuita que permite instalar e executar scripts. Scripts são pequenos códigos, criados para realizar uma tarefa específica automaticamente ou melhorar uma página. Aqui, eles ajudam em tarefas da rotina docente.

Como instalar em 4 passos

1
Instale o Tampermonkey

Escolha o navegador que você usa e, na página que abrir, clique em “Adicionar” ou “Obter”.

Importante: nessa página, ative a opção “Permitir Scripts de Usuário”. Ela é necessária para que os scripts desta página funcionem. Instale apenas scripts de fontes em que você confia.

Como funciona o lançamento por planilha

Esse script foi pensado para o ambiente da Sala do Futuro, especialmente na tela de Diário de Classe → Lançamento de avaliações → Editar notas. Quando ativado, ele cria um botão de Lançamento por planilha na própria interface de notas.

Formato esperado: a planilha deve conter apenas os dados de nome e nota, sem título na primeira linha. O script lê cada linha, identifica o aluno e aplica a nota correspondente ao nome.

Para copiar: selecione os nomes e as notas correspondentes na planilha e copie com Ctrl + C no Windows. Depois cole na janela do script para que ele possa identificar cada aluno e aplicar a nota correta.

Importante: os nomes precisam ser exatos para que a nota seja aplicada corretamente. Se houver qualquer diferença no nome, como acentos, espaços, letras maiúsculas/minúsculas ou escrita diferente, a busca não encontrará o aluno e a nota não será lançada.

Como funciona o script de melhorias no fechamento de avaliações

Este script foi desenvolvido para facilitar o fechamento de avaliações na Sala do Futuro.

Uma das principais funcionalidades é o botão de Arredondar notas, que permite ajustar rapidamente as notas dos alunos para valores inteiros ou com uma casa decimal, conforme necessário.

O arredondamento é realizado da seguinte forma: notas com decimais maior ou igual a 0,5 é ajustado para o próximo valor. Exemplo: 4,5 -> 5.0 4,4 -> 4.0

Importante: o script foi projetado para funcionar apenas na tela de fechamento de avaliações da Sala do Futuro. Certifique-se de revisar os ajustes antes de finalizar o processo.

Educação Profissional: melhorias específicas para a rotina do professor

Esse script é voltado especialmente para quem atua no Ensino Médio Técnico e usa o portal da Educação Profissional no dia a dia. Ele foi pensado para reduzir a quantidade de cliques, facilitar a navegação e criar atalhos mais diretos para informações e relatórios que costumam ser repetitivos.

Uma das principais melhorias é a exportação de relatórios em CSV: o script permite nomear a turma e fazer o download em um formato como TURMA_Disciplina_Bimestre. Esse padrão foi pensado para conversar diretamente com a ferramenta Pendências de atividades, que usa esse mesmo formato para gerar relatórios agregados, organizando os dados de forma mais rápida e consistente.

Em meu repositório do GitHub, eu comento cada funcionalidade e explico como elas foram pensadas na prática: ver documentação e detalhes do script ↗

Como funciona o download na Árvore de Materiais

Na página de materiais da Educação Profissional, o script adiciona o botão Baixar vários arquivos. Com ele, você pode escolher materiais individualmente ou filtrar por formato, como PDF e PPTX, e baixar os itens selecionados juntos em um arquivo ZIP.

Os arquivos ficam mais fáceis de identificar: o nome inclui o componente curricular, o bimestre, a semana e o formato. Por exemplo: Programação Mobile - 4º Bimestre - Semana 28 - PDF.zip.

Dica: o script considera os materiais carregados na página. Role a árvore para carregar os itens desejados antes de abrir a seleção para download.
